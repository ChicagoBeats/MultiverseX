OPTIONAL: README.md  .gitignore  START-HERE.txt

INSTALLING (important):
  1. From the artifact, take the single file inside  MultiverseX.vst3 > Contents > x86_64-win  (64-bit)  or  x86-win  (32-bit).
  2. Rename it MultiverseX_0_7.vst3 and put it where your working MultiverseX_0_2.vst3 is.
  3. Leave v0.2 alone - v0.7 has its own plugin ID now, so they no longer clash.
  4. Delete any OTHER old MultiverseX builds (v0.3-v0.6) from every plugin folder; they all share one ID with each other.
  5. In FL: rescan plugins, then add it in a NEW EMPTY project first.

RULE: whenever you want two builds installed at the same time, change PLUGIN_CODE in CMakeLists.txt (4 letters) for the new one.
